### .NET Console App Setup with CLI

1. Create project:
   ```bash
dotnet new console -o MyApp
   ```
2. Navigate:
   ```bash
cd MyApp
   ```
3. Edit `Program.cs`.
4. Run:
   ```bash
dotnet run
   ```

Supports .NET 6+ top-level statements.
